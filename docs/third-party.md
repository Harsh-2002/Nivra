# Third-party notices

Nivra's own source is MIT licensed. The production image includes `/app/THIRD_PARTY_NOTICES.txt`, generated from the production dependency closure and the packages traced into the Next.js standalone runtime before native pruning. It records each package's name, version, installed path and declared license metadata, and includes readable upstream license, copyright and notice files found in the installed packages. The collector also verifies and includes the pinned upstream texts listed below. A missing-text entry is explicit; an SPDX identifier is not substituted for license text. It exits unsuccessfully when a critical runtime package lacks full license text or when a bundled Excalidraw font has no verified exact upstream license.

- Node.js: MIT, with bundled third-party notices. The Debian runtime retains the full license at `/usr/share/licenses/node/LICENSE`. Both architectures verify the license hash for the pinned Node release; update it when changing the base image.

- BlockNote core, React, shadcn, code-block, and diagram-block and server-util packages: MPL-2.0. No XL packages are used. The image inventory includes package-provided license text where present. Modifications to covered upstream source remain subject to its license; Nivra's custom blocks are maintained separately.
- Excalidraw: MIT, with the `v0.18.1` upstream license text bundled and hash-verified. The nine font directories copied from that pinned package each have a separately included full font license and provenance record. The build collector verifies that the public font files and hashes match the installed package, checks each vendored notice hash, and fails if an asset has no mapped license text. Generated assets are copied locally rather than fetched from a CDN.
- Shiki core, JavaScript engine, precompiled languages and themes, Mermaid, and DOMPurify: MIT. The published reader reuses pinned versions already present in the editor dependency tree.
- Geist: SIL Open Font License 1.1, distributed through `@fontsource-variable/geist`.
- Tesseract.js and its WebAssembly core: Apache-2.0. The English OCR file is copied from the build-only `@tesseract.js-data/eng@1.0.0` package into `generated/ocr/4.0.0_best_int/eng.traineddata.gz` after its pinned SHA-256 is verified. The pinned `naptha/tessdata` README identifies the file as integerized Tessdata Best and links its model source to `tesseract-ocr/tessdata_best`; the provenance excerpt, source hashes, and full upstream Apache-2.0 data license are included with the notice. The npm wrapper declares MIT but does not provide its full MIT text; that gap remains unresolved, and the wrapper, package metadata, and other language assets are excluded from the runtime image. unpdf: MIT.
- Sharp: Apache-2.0. OCR uses it for EXIF orientation and complete quarter-turn images before recognition; package-provided texts for Sharp and its native packages are collected into the image inventory. The traced platform `@img/sharp-libvips-linux-{x64,arm64}@1.3.4` package includes libvips `8.18.7`; the collector records its `versions.json` hash and bundled library hash, and includes the pinned upstream third-party notice and LGPL/GPL texts. This explicitly pins the image library already present through Next.js.
- shadcn/ui, Next.js, React, Better Auth, and Lucide are represented in the image inventory by their package versions and declared license metadata. Any absent package-provided license text is marked as missing there. Drizzle ORM's Apache-2.0 text is included from its pinned upstream `0.45.3` source.
- parse5: MIT. Bookmark metadata uses its inert HTML parser, pinned from the existing dependency tree.

The installed `onnxruntime-node@1.30.0` and `onnxruntime-common@1.30.0` npm packages omit their full license text. The build includes the official `v1.30.0` MIT license and `ThirdPartyNotices.txt`, verified against the source hashes below, so notices for native-binary dependencies are retained as well. Review dependency advisories when updating; do not use `npm audit fix --force` to silently downgrade the editor or framework.

- `@napi-rs/canvas`: MIT. Local PDF thumbnail rendering uses its packaged native Canvas implementation; discovered upstream texts are included in the image inventory. FFmpeg is provided by the runtime distribution for video thumbnails; Debian package copyright notices are under `/usr/share/doc` and FFmpeg's license depends on that distribution's build and bundled codecs.

- Official Model Context Protocol TypeScript server/client SDKs and `jose`: MIT. Better Auth MCP, client-metadata and API-key plugins are listed with their Better Auth package licenses in the image inventory. `y-prosemirror` is MIT licensed and supplies the headless Markdown parser's ProseMirror peer integration.

- `@dnd-kit/react` and `@dnd-kit/dom`: MIT. Task boards use their pointer and keyboard drag controls; package-provided notices are collected into the image inventory.

- Snowflake Arctic Embed XS q8 weights and tokenizer configuration: Apache-2.0, pinned to revision `d8c86521100d3556476a063fc2342036d45c106f`. The Docker model pack includes LICENSE, NOTICE and checksums. ONNX Runtime Node: MIT, CPU binaries only; its npm packages omit full license text, so the pinned upstream texts are bundled as described below. `@huggingface/tokenizers`: Apache-2.0 with its package-provided text included in the inventory. Models load locally; no inference-time downloads or external inference services.

- Encrypted SQLite: `better-sqlite3-multiple-ciphers` is MIT licensed and its package license is included in the image inventory. Its bundled SQLite3 Multiple Ciphers v2.4.0 source carries a separate MIT copyright/license header. The image includes the full upstream v2.4.0 license and also reproduces the embedded source header.
